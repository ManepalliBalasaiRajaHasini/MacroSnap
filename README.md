# 🥗 MacroSnap – AI Nutrition Buddy

MacroSnap is an AI-powered nutrition chatbot built using Streamlit and Gemini Vision.

Users can upload a photo of their meal or type a food-related question. MacroSnap analyzes the meal and provides estimated calories and macronutrients such as protein, carbohydrates, and fat.

## ✨ Features

- 📸 Upload a meal photo
- 🤖 AI-powered meal analysis using Gemini Vision
- 🔥 Estimated calories
- 💪 Estimated protein
- 🍚 Estimated carbohydrates
- 🥑 Estimated fat
- 💬 AI nutrition chat
- 📊 Simple nutrition summary
- 🎨 Premium glassmorphism UI
- 🔐 Secure API key using Streamlit Secrets

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Gemini Vision
- HTML & CSS
